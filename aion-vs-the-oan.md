The OAN is the name Aion adopted for its public-facing network in November 2019, while AION stayed the name of the token, so the two terms describe one project at two points in its history.

Nothing about the chain changed with the name. The same mainnet, the same chain ID 256, the same virtual machine, and the same asset under a new umbrella.

## You'll see this if

- Documentation you are reading switches between Aion and The OAN.
- You are unsure whether The OAN is a different network.
- A search result for one name returns material about the other.
- You want to know which name to use when you describe the project.

## What changed

The rebrand was about positioning. The Open Application Network framed the project around applications built across chains, rather than around the chain itself as a destination.

What changed was the framing and the domains: public material moved to theoan.com addresses, and the network's documentation, validator pages and wallet were published under that name.

What did not change: consensus, the virtual machine, the token, the address format and the chain identifier. A wallet configured for mainnet before the rebrand still connects today.

## What did not change, in detail

Consensus stayed Unity, alternating proof-of-work and proof-of-stake blocks.

Execution stayed on the AVM, with Java bytecode rather than EVM bytecode, which is why the [Aion Java smart contract](https://github.com/aion-wallet/aion-explained/blob/main/aion-java-smart-contract.md) article applies regardless of which name a page uses.

The token stayed AION. No new asset was issued, and no conversion was required for holders.

Addresses stayed `0xa0` prefixed, 66 characters, as described in the [Aion address format](https://github.com/aion-wallet/aion-wallet-help/blob/main/aion-address-format-0xa0.md) guide.

## Which name to use now

Both appear, and neither is wrong. "Aion" is the name of the network and the token and remains the common term in wallets and exchanges; "The OAN" appears in the historical documentation and in material published during that period.

When you are searching, use both: a query for one name will miss pages published under the other, which is exactly the problem the rebrand created for readers.

## Why the two names cause confusion

Readers interpret a name change as a project change. Someone who finds Aion material from 2018 and OAN material from 2020 reasonably concludes that one project replaced another.

The second cause is that the rebrand did not coincide with a technical event. There was no migration, no new chain and no token swap attached to it, so there is no obvious marker in a wallet or an explorer that tells a reader the names are the same thing.

## The related history worth knowing

Two other events are often folded into the same story and should be kept separate.

The ERC-20 token swap ran until January 2022 and then closed, which is a change to a conversion route rather than to the network, covered by the [Aion token swap closed](https://github.com/aion-wallet/aion-explained/blob/main/aion-token-swap-closed.md) article.

The ecosystem contracted, with some wallets and services dropping support. That is a fact about third parties rather than about the rebrand.

One more consequence is worth knowing: support material written during the OAN period describes the same validator roles and the same staking bonds under a different vocabulary. A reader who follows an OAN-era staking page will still find the mechanics correct, which is itself evidence that the rebrand was a name change rather than a redesign.

## Prevention

Date the material you read. A page that uses one name exclusively is telling you when it was written.

Prefer the release page and the wallet repository for anything operational; naming history does not affect which installer is current.

When you describe the project to someone else, use the pair: Aion, also known as The OAN. It prevents the next reader from repeating the search.

## What the domains tell you

The rebrand moved public material onto theoan.com addresses, which is why a search for Aion documentation can land on a domain that does not contain the word Aion at all. That is a naming consequence, not a sign of a different project.

It also means link rot. Guides written before 2019 point at addresses that later redirected or disappeared, and a reader who follows one and finds a dead page reasonably concludes the project is gone. The [what happened to Aion](https://github.com/aion-wallet/aion-explained/blob/main/what-happened-to-aion.md) article covers the sequence that produced those links.

For anything operational, prefer the release page of the repository and this account's wallet, both of which are independent of the naming period. A version and a date are unaffected by a domain change.

## Frequently asked questions

### Is The OAN a different blockchain?

No. It is the name the project adopted for its network in 2019.

### Did the token change name too?

No. AION remained the asset name throughout.

### Do I need to do anything because of the rebrand?

No. Wallets and addresses were unaffected, and no conversion was ever required.

### Why do some sites still say Aion?

Because the token and the network are still called Aion in most tooling, and because the rebrand was a positioning change rather than a technical one.
